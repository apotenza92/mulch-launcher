<h1 align="center">MulchLauncher</h1>

<p align="center">A game launcher for Windows.</p>

<p align="center"><a href="https://apotenza92.github.io/mulch-launcher/">Download</a></p>

It shows the games installed by Steam, Epic, Ubisoft Connect, GOG, Xbox,
Battle.net, Rockstar and EA, plus any you add yourself.

![The library](docs/screenshots/library.png)

- Games are found from each launcher's own records and played through it.
- Games are grouped by when you last played them.
- It updates itself.
- Uninstall from Windows Settings; it removes everything it added.
